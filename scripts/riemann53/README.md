# Fixed state-53 pilot runner

Current disposition: the first remote run failed before generation because the
capacity probe assumed a missing cgroup-v2 file. The optional v1/v2 probe repair
is unexecuted. A direct source proof then refuted the canonical E/pop equation
at outside44 (see research/riemann-reduction/pilot-53/COUNTEREXAMPLE.md).
Do not rerun this route or treat any planned checks below as executed evidence.

Execute only through the dedicated remote workflow. Local use, including fixture
execution, generation and counting, is intentionally rejected by the scripts.

One candidate: change old 40/ONE's destination from 53 to 68, delete state 53,
and densely relabel. No other optimization operator is implemented.

The first tier reads the actual pinned schema/effect arrays as strict data and
checks the required equation

```text
E(returned(cont, k, walked)) = returned(cont, k, E(walked))
```

E deletes bits read by old 53 on the old read-preserving root walk. It leaves
other bits in order; a non-parser suffix is retained verbatim. At full frames,
the padding index decreases by the number of removed walked bits. The first
failure is chosen by walked length, walked lexicographic order, then schema ID
within the fixed 97-outside-word tier. No claim of global minimality is made.
Stop on a false equation rather than expanding to additional depths/operators.

For a failure, run the old and new complete literal machines from recorded root
frames to their first subsequent root, recording full finite nonzero tape
supports, heads, native bank effect and source hashes. Node independently parses
all literal cells, checks the precise transformation and count, binds the witness
to source arrays, recalculates the pop and E map and replays both full tapes.
The mismatch rejects this encoding/proof route; it does not prove inequivalence
of the two blank runs or impossibility of a different encoding or 94-state TM.

No proof of RH equivalence is attempted after a rejection. A passing finite tier
would leave universal encoding closure, candidate Lean proof, independent
Challenge/comparator and full foundations audits open. Such a result is never
credited as a reduction. No fresh Lean or baseline replay runs in the negative
path. The runner reports an open obligation if its finite tier finds no witness;
it cannot silently accept the candidate.

Budget: one ordinary public free runner, 3180 seconds including measured setup,
6 GiB process group plus driver RSS, 512 MiB driver address-space/RSS upper bound,
one candidate, at most 128 frames/depth <=3, 2,000,000 TM steps, no retries.
The implemented negative tier uses 97 outside schemas and two frame simulations.
No generated Lean source or local proof tool is involved. Future positive proof
work must retain -M6144, strict linting and <=100-character new/generated lines.
