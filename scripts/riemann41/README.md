# Authorized 41/ONE proof-only pilot

This is one fixed remote recipe, not a search or candidate generator. Every
executable requires RH41_REMOTE=1 and GITHUB_ACTIONS=true; the driver additionally
requires the public bocowgill fork, ordinary GitHub-hosted runner, exact branch,
attempt 1 and a parent-bound launch packet. No local Lean or simulation is allowed.

The workflow triggers only on launch.json; source transport uses skip CI. Keep
the accepted machine, manifest, toolchain, specification and old evidence unchanged.
The user authorized one free job with no retry, not a larger machine search.

The phases are literal provenance/fidelity, fixed finite filters and independent
replay, setup/cache, strict local kernel checks, the assembly probe, and a
full-private audit plus explicit rejection controls. Every real Lean invocation
is serialized under the -M6144 wrapper, including dependency builds. Wall/RSS
caps and the optional cgroup probe are enforced by driver.py.

GuardLiteral is generated remotely from all 190 accepted literal cells; it also
checks that the selected callers have actual DEC-j effects. GuardCore proves
the separator step and a conditional isolated-overwrite theorem. GuardBoot
attempts all-prefix safety through the actual 3634-step initializer, with an
explicit soundness bridge from the finite list-tape evaluator to actual nSteps.
These facts alone do not establish unbounded avoidance.

AssemblyProbe attempts the earliest missing strengthening of root_native: the
same complete root-frame endpoint plus PrefixSafe through every intermediate
time. It reuses the existing endpoint theorem and tries bounded kernel-producing
automation on the remaining goal. An unsolved goal is retained verbatim, not
replaced by an axiom, sorry or assumed guard. The probe is excluded from audit
roots unless a complete later assembly is actually supplied and checked. Even
success of this one lemma leaves jump/return/stage/global coverage obligations;
the driver reports those as open, never a global theorem.

On a failed strict proof build, the driver audits only modules with fresh built
artifacts, records the exact first failed build/goal, and attempts the controls.
It never retries the build. A resource stop halts the recipe. Positive finite
filters certify only those finite traces. No unconditional isolation theorem,
state saving, candidate table or new RH theorem is claimed without its proof.

The finite boot runs exactly 3634 steps, below the proposed 20000-step bound;
intermediate visits to state 15 are not mistaken for completion. Each fixture's
initial support plus all state/head/read/write/move deltas and final support
encode the complete tape at every step without dropping blank coordinates.
Independent Node code reconstructs and compares each trace and full tape.

The user authorized one additional repair-verification job on 2026-10-25. It uses
launch-verify02.json and .lake/riemann41-verify02; it does not overwrite the first
artifact. Its preflight binds the exact namespace/deprecation/Bool compatibility
substitutions to the failed producer and requires seven finite/source receipts
to match the retained first run. All original limits and proof boundaries remain.
