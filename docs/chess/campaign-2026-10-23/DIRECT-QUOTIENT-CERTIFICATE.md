## Generic mathematical interface

For any getter graph with the frozen strict pure-child descent property, let
observe_b map an auxiliary descriptor/command to an arbitrary result type.
Require C to satisfy the six local equations:

- Move/write: C is observe_b of that primitive's exact child/store/command.
- Load: C(i,b,v)=C(child,b,table(b,v)).
- Branch: C equals the selected child's C at the same bit/store.
- Goto: C is observe_b of the actual label entry/current store/write-b.
- Halt syntax: C is observe_b of halted descriptor/current store/write-b.

Well-founded induction on the pure children proves C(i,b,v)=observe_b(trAux).
Goto/control cycles are preserved; there is no assumption that chess terminates
or that the complete control graph is acyclic. The prototype also proposes a
generic exact source-slot transport and surjectivity theorem over arbitrary rows,
layouts and equal decoded syntax. This part is independent of full source-table
reconstruction; applying it to all actual decoded operations requires that gate.

Choose observe_b to encode the actual compiled binary row AFTER mapping its
destination through classMap. Choose C directly from the already certified Q
and classMap tables. No separately proposed cache is mathematically necessary.
An optional checked memo table can be considered only if measured lookup cost
justifies it. No cache-data reduction changes the physical machine state count.

## Eliminate three proof-data categories

1. Use the exact decoded operation's lower/fastNodeAt and the generic source-slot
   theorem. This avoids a separately proposed106668node graph and its fidelity
   proof. All original source operations and source layouts remain fixed.
2. Use C defined directly from Q/classMap. This avoids a separate auxiliary-result
   or packed binary-row cache and its full-data fidelity proof. Checking local
   closure is sufficient only with the generic soundness and full coverage proof.
3. Use the frozen findReturn_syntax and local findTarget on the decoded syntax.
   For literal writes, a checked local return rank plus certified return prefix
   gives the actual paid bounce address. Goto targets use their source root's

   the exact targetAt slot. This may avoid a separately proposed40461row global
   return-decoding dump and expensive global inverse evaluation. Complete return
   coverage and local-rank correctness still require proofs.

Check node/return prefix tables once through a linear checked scan and universal
prefix soundness, rather than repeating closed take/sum proofs for numeric labels.
Existing exact weight/prefix identities are ingredients; this new fast prefix
representation is not implemented or proved. Local target calculations still
need measured costs; do not assume they are free or uniformly tiny.
