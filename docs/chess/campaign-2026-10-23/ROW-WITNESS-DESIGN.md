This is a proof-engineering plan, not a proved certificate or accepted saving.
The target stays RowAt for the same measured class map and quotient. Its sole
identified payoff is the459315state full-machine reduction to310029.

1. Prove the frozen Post live equation, local getter equation, actual initial
   entry and numeric CompactPost permutation. Audit all helper roots.
2. Transport each touched row once from Vector.get to a named

   equality cast, so subsequent local proofs never normalize Vector.ofFn.
3. Prove a touched label's offset once and its local-node addresses through
   code_val, keeping the global inverse equivalence opaque. Check the far end
   of the layout in a bounded preflight before expanding the sample.
4. Propose literal local nodes from the pinned native snapshot, prove their
   equality with fastNodeAt, and transport through getter_local. Cache child

   equations instead of reducing its well-founded recursion.
5. Prove actual numeric binary rows via SelectiveBinary.compile_main or
   compile_bounce. For writes, transport findReturn_live and returnAt_live
   through local target ranks; cache return offsets and paid numeric addresses.
   Finish each unchanged RowAt by only the small map/quotient lookups.
6. Measure the same64states/both bits, meaningful kernel false-row control,
   then512/4096. Flush a durable progress marker per completed row. Complete
   universal coverage separately using a balanced structural certificate.

The snapshot proposes witnesses only; every address, node and transition must
be checked by ordinary Lean proof terms. Its stored numbers do not establish
correspondence. Neither representative sampling nor native differential checks
close the universal RowAt theorem. Do not reuse the source CodeDAG's acyclic
decoder for a cyclic Turing machine.

offset preflight would justify one structural balanced prefix certificate,
not increasing caps or repeating global normalization. A costly local-node
proof would justify caching syntax constructor equations before expanding
sample sizes. Keep all accepted and frozen files fixed.
