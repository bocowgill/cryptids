# Conditional fallback: certify structural tables once

Status: design only; no implementation or proof credit. Current diagnostic run34
must finish before choosing this route. Its prospective full-machine saving is
within the same 459,315 states, not an additional reduction. Accepted best remains
769,344; target 310,029 includes every other paid control.

The current method proves a concrete getter equation, an auxiliary interpretation,
an actual binary transition and its quotient equation for selected states. Even a
successful 4,096-state pilot would not establish all 573,802 states. Measure setup,
per-node and per-row costs; do not extrapolate a few markers as accepted theorems.
A million separately elaborated row theorems may be the wrong certificate format.

A possible architecture is to expose the original compiler as cheap literal tables
through universal structural correctness, then check the quotient over those
literals. This keeps the actual source machine in the final theorem.

1. Give each source syntax row an executable node serialization. Prove universally
   that indexing this serialization at a local syntax slot produces its exact
   `fastNodeAt`, including all ten bit/store table cells and renamed child indices.
   Use the already certified shared node-weight prefixes for global addresses.
2. Prove the complete serialization matches an untrusted proposed numeric graph
   dump. Reuse the frozen 127 source-operation chunks and named balanced-parent
   congruences. Kernel-check original source correspondence, not only dump validity.
3. Certify literal entry and return tables against the original layouts, including
   every root, write-child/store pair, halt return and inverse lookup. Graph-node
   fidelity alone does not identify the binary body: its return allocation matters.
4. Establish a generic cache-soundness theorem for `LazyGraph.trAux`. A proposed
   result at every node/bit/store must satisfy the actual node equation. Recursive
   obligations descend only through strict syntax children. A goto returns an
   observable write and entry target; never assume the whole machine is acyclic.
5. Rewrite the original selective body through the certified tables/cache, and use
   a balanced one-pass quotient checker over cheap numeric literal rows. Include
   missing transitions and both bits. Connect the resulting universal relation to
   the existing arbitrary-tape halting theorem and paid complete-machine linkage.

Every step above is unproved in this proposed representation. Existing generic
local-slot, source-weight and return-transport lemmas supply ingredients, not the
complete result. Native evaluation may propose witnesses only. Foundation audits
must reject `sorryAx`, `Lean.ofReduceBool`, new axioms or unsafe proof dependencies.

A bounded pilot should first test one routine family with distant source labels,
nonconstant bit/store tables and all constructor kinds it uses. Check exact source
and return fidelity plus a deliberately corrupted table cell. Keep the existing
6GiB/60-second helper cap and retain all source/diagnostics before scaling. If the
serialization still normalizes global layout inverses, correct that representation
before retrying; do not raise the cap. The pilot is useful only if it removes a
measured large cost of the full certificate.

Opportunity ranking is unchanged: measured whole-body quotient first (459,315;
high proof difficulty); this fallback is a certificate dependency for that same
saving (high proof difficulty, moderate-to-high implementation effort). Packet
compression comes next only with fully paid decoder/control estimates. An entirely
new interpreter has no defensible net estimate and remains lower priority.
